# North Star Bakery — Touchstone 3

This repository contains the North Star Bakery multi-page website for Touchstone 3.

## Files
- `index.html` — Home
- `products.html` — Products
- `about.html` — About
- `contact.html` — Contact
- `style.css` — External visual design system and responsive layout

## Design system
- Cream: `#FFF8F0`
- Warm brown: `#6B3E26`
- Peach: `#D88C5A`
- Charcoal: `#2F2A26`
- Headings: Georgia
- Body/navigation: Arial
- Layout: mobile-first Flexbox
- Responsive breakpoint: 800px

## Media files
The HTML references the media files supplied with the Touchstone 2 bakery client materials:
- bakery-logo.png
- bakery-storefront.jpg
- bakery-bread.jpg
- bakery-signature-loaf.jpg
- bakery-feature-small.jpg
- bakery-feature-large.jpg
- bakery-welcome.mp3
- bakery-behind-scenes.mp4

Add those supplied media files to the repository's root folder before publishing the final website.

## Important
The address, hours, and other business details in the HTML are sample values because the client brief did not provide official contact details. Replace them if your instructor/client provides official information.
